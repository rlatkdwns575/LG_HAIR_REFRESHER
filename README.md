# LG Hair Refresher

> 향으로 덮지 않고, 공기로 리셋하는 개인 맞춤형 헤어 리프레시 경험

LG Hair Refresher는 헤어 리프레셔 디바이스와 연동해 모발과 두피 상태를 측정하고, 냄새·먼지·헤어 컨디션 데이터를 기반으로 사용자에게 적절한 리프레시 모드를 추천하는 Flutter 모바일 앱입니다.

사용자는 앱을 통해 현재 헤어 상태를 확인하고, 상황에 맞는 리프레시 모드를 실행하며, 리프레시 전후 변화를 기록으로 관리할 수 있습니다.

---

## 프로젝트 배경

외출, 운동, 회식, 대중교통 이용 후에는 모발에 냄새와 먼지가 쉽게 남지만, 매번 머리를 감는 것은 시간적·신체적으로 부담이 큽니다.

기존의 헤어미스트나 드라이샴푸는 냄새를 향으로 덮거나 일시적으로 보송하게 만드는 방식에 가까워, 사용자가 실제로 얼마나 깨끗해졌는지 확인하기 어렵다는 한계가 있습니다.

LG Hair Refresher는 모발과 두피 상태를 측정하고, 냄새·먼지·헤어 컨디션 데이터를 바탕으로 사용자에게 적절한 리프레시 모드를 추천합니다.

이를 통해 사용자는 샴푸 없이도 현재 헤어 상태를 확인하고, 상황에 맞는 관리 루틴을 만들 수 있습니다.

---

## 문제 정의

- 사용자는 머리 냄새와 떡짐, 먼지 잔여감을 느껴도 실제 상태를 객관적으로 확인하기 어렵습니다.
- 향 제품은 냄새를 제거하기보다 덮는 방식이기 때문에 근본적인 해결감이 부족합니다.
- 외출 전후, 운동 전후, 회식 후처럼 상황별로 필요한 헤어 관리 방식이 다르지만, 기존 제품은 개인 상태에 맞춘 추천이 어렵습니다.
- 사용 기록이 남지 않아 사용자가 자신의 헤어 컨디션 변화나 관리 패턴을 확인하기 어렵습니다.

---

## 서비스 목표

LG Hair Refresher 앱은 사용자가 자신의 헤어 상태를 직관적으로 이해하고, 상황에 맞는 리프레시 모드를 실행하며, 사용 결과를 기록으로 관리할 수 있도록 돕는 것을 목표로 합니다.

핵심 목표는 다음과 같습니다.

- 모발·두피·냄새·먼지 상태를 측정해 현재 헤어 컨디션을 시각화합니다.
- 측정 결과를 바탕으로 사용자의 상황에 맞는 리프레시 모드를 추천합니다.
- 리프레시 실행 전후의 오염도 변화를 보여주어 관리 효과를 확인할 수 있게 합니다.
- 사용 기록을 저장해 사용자가 자신의 헤어 관리 패턴을 확인할 수 있게 합니다.
